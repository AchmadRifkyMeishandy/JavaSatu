# Latihan Dasar Pemrograman Java

Repository berisi contoh-contoh kecil untuk mempelajari dasar bahasa pemrograman Java. File di folder `src/` dipisahkan berdasarkan topik agar mudah dibaca dan dicoba satu per satu.

## Materi

- Output program, komentar, variabel, dan tipe data.
- Operator matematika, perbandingan, dan boolean.
- Percabangan `if`, `switch`, dan operator ternary.
- Perulangan `for`, `while`, `do-while`, `break`, dan `continue`.
- Array dan `for-each`.
- Method, parameter, return value, overloading, recursion, dan variable arguments.
- Input pengguna dengan `Scanner`.

## Menjalankan Contoh

1. Pastikan JDK terpasang.
2. Buka proyek dengan IDE Java atau buka folder `src/`.
3. Jalankan satu kelas latihan, misalnya `HelloWorld.java` atau `IfStatement.java`.

Contoh melalui terminal dari root repository:

```bash
javac -d out src/HelloWorld.java
java -cp out HelloWorld
```

Repository ini merupakan catatan praktik untuk memperkuat fondasi Java dan menjadi bahan eksperimen saat mempelajari konsep berikutnya.
